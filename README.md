# 🌍 MundoCulturas

**Plataforma web premium para explorar culturas del mundo** — Diseñada con estándares de calidad Google Earth + National Geographic + Duolingo.

## ✨ Características Implementadas

- **Globo 3D Interactivo** (Three.js + React Three Fiber)
  - Rotación fluida con auto-rotate
  - Zoom suave
  - Nubes dinámicas
  - Atmósfera realista + iluminación cinematográfica
  - 12 pins interactivos clicables con etiquetas premium
  - Efectos de hover y glow

- **Diseño Premium**
  - Totalmente responsive
  - Modo oscuro elegante
  - Animaciones fluidas con Framer Motion
  - Glassmorphism y micro-interacciones
  - Tipografía profesional (Geist + Playfair Display)

- **Sistema Multilingüe** (ES / EN)
  - Cambiador de idioma persistente
  - Todas las secciones traducidas

- **Páginas Completas**
  - Inicio con Hero cinematográfico + Globo 3D
  - /explorar — Grid de países con búsqueda y filtros
  - /mapa — Vista tipo mapa 2D
  - /juegos — Juegos educativos (Adivina la Bandera + Pasaporte Mundial)
  - /paises/[slug] — Perfiles completos con tabs y galería

- **Gamificación**
  - Pasaporte Mundial con sellos persistentes
  - Quiz de banderas con puntuación

## 🚀 Cómo ejecutar

```bash
npm install
npm run dev
```

Abre http://localhost:3000
